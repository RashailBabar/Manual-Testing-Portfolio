
**# Bug Report**

**Bug ID:** BUG-001

**Title:** User can log in with an incorrect password

**Description:**
The application allows a user to successfully log in even when an incorrect password is entered for a valid registered email address.

**Steps to Reproduce (STRs):**

1. Open the login page.
2. Enter a valid registered email address.
3. Enter an incorrect password.
4. Click the **Login** button.

**Expected Result:**
The system should reject the login attempt and display an appropriate error message indicating that the email or password is incorrect.

**Actual Result:**
The user is successfully logged in despite entering an incorrect password.

**Environment:**
* Application: Demo E-Commerce Application
* Browser: Google Chrome
* OS: Windows 11
* Environment: Test

**Severity:** High

**Priority:** High

**Bug Type:** Functional / Security
